## Summary
A Show HN project enabling AI agents running on different computers to collaborate on tasks. Posted Aug 28, 2026. Solves the problem of agents being isolated to single machines — enables distributed agent orchestration.

## Idea angle
Distributed agent coordination is the next frontier after single-machine agents. If agent A on your laptop can delegate to agent B on a server with GPU access, you get elastic agent compute. This is the agent equivalent of MPI for HPC — foundational infrastructure for multi-agent systems.
