# DSA: Evidence-Aware LLM-Agent Orchestration for Multi-Market Stock Research
**Date:** 2026-08-29
**Keyword:** finance
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.26990v1

## Summary
A paper proposing DSA, an evidence-aware orchestration framework for LLM agents doing multi-market stock research. The system assembles heterogeneous evidence, exposes unavailable data and model capabilities, and controls the reasoning pipeline. Published Aug 27, 2026.

## Idea angle
Evidence-aware orchestration solves the hallucination problem in LLM financial analysis — the agent knows what data it has, what it doesn't, and reasons only from available evidence. This is the architecture for trustworthy AI financial research: no more confident-sounding analysis based on missing data.
