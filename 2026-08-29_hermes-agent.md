## Summary
An AI agent platform from NousResearch that doesn't assume the agent lives in one place — it follows the user across contexts (chat, terminal, messaging, internal systems). Updated every minute, actively developed. Noted by ODSC as a top agentic AI repo of 2026.

## Idea angle
The 'agent follows you across contexts' paradigm is the right abstraction for personal productivity. Instead of separate AI tools for email, code, and research, one agent with persistent memory spans all surfaces. This is architecturally harder but delivers more value than context-switched agents.
