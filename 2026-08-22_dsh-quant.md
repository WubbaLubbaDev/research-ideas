## Summary
Dsh-Quant is a plugin for the DeepSeek Harness ecosystem that turns it into an AI-native quantitative trading OS. It extends a general agent harness with quant-specific workflows.

## Idea angle
The plugin ecosystem pattern is interesting — build domain-specific finance plugins for existing agent platforms rather than standalone apps. Could create a similar plugin for IDX/Crypto trading on top of open agent frameworks.
