## Summary
A GitHub repo using YOLOv8 for real-time detection and automated counting of palm oil fruit bunches (TBS — Tandan Buah Segar), classifying them as Matang (ripe), Mentah (unripe), and Cacat (defective). Practical on-device detection for plantation use.

## Idea angle
Automated fruit bunch classification at the edge enables real-time harvest readiness assessment without sending data to the cloud. For Indonesian smallholders, a mobile app using this model could replace manual grading at the mill — reducing disputes and improving pricing transparency.
