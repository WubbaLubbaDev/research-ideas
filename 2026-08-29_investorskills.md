## Summary
A 1.4K-star repo (created May 2026) that packages investing workflows as reusable 'skills' for AI agents — similar to how coding agents have skills, this gives trading agents structured analysis capabilities (fundamental screening, technical analysis, risk assessment).

## Idea angle
The 'skills for agents' pattern has proven itself in coding (Claude Code, Hermes Agent). Applying it to investing is natural — an agent with a 'DCF valuation skill' or 'options Greeks skill' is more useful than a generic chatbot. Could build similar skill packs for IDX-specific analysis.
