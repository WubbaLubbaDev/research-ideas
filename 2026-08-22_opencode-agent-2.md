# OpenCode — Open Source AI Coding Agent
**Date:** 2026-08-22
**Keyword:** AI agent
**Source:** Hacker News
**URL:** https://opencode.ai/

## Summary
OpenCode is an open-source AI coding agent that runs in the terminal. It provides a CLI-first alternative to Cursor and GitHub Copilot, with support for multiple LLM backends and extensible tooling.

## Idea angle
The terminal-first agent pattern is worth studying for building finance-focused coding agents — a CLI tool that can both write code and query financial APIs would be useful for quant developers who live in the terminal.
