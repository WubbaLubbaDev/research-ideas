## Summary
A developer tool that provides full company context to every AI agent, eliminating the cold-start problem where agents don't understand your business. Rated 4.0/5 on Product Hunt.

## Idea angle
Context injection for agents is an infrastructure problem — how do you securely give an agent access to your company's docs, codebase, and data without dumping everything into the prompt? A RAG-based context layer that agents query on-demand, with permission scoping, would be the open-source answer. The 'company brain' pattern is reusable across any agent framework.
