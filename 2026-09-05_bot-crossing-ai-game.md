## Summary
A video game designed specifically for AI agents to play — essentially Animal Crossing for bots. Agents must navigate environments, manage resources, and make decisions in a gamified sandbox. 155 stars this week.

## Idea angle
Games as evaluation environments for AI agents is an emerging paradigm. A sandbox game where agents must plan, prioritize, and interact with NPCs tests capabilities that benchmarks miss — long-horizon planning, resource allocation, social reasoning. Building an API layer that lets any LLM agent plug into this game would create a standardized 'agent IQ test' that's more fun and more revealing than static benchmarks.
