# Open Finance MCP — Connect Bank Accounts to AI
**Date:** 2026-08-22
**Keyword:** finance
**Source:** Product Hunt
**URL:** https://www.producthunt.com/products/open-finance-mcp/awards

## Summary
Open Finance MCP connects bank accounts to ChatGPT, Claude, and any MCP-compatible AI through Brazil's Open Finance system. Users can ask about spending, get financial insights, and automate budget tracking via natural language.

## Idea angle
Build a similar MCP server for Indonesia's open banking infrastructure (Bank Indonesia's open API standard). The gap: Indonesia has open banking APIs but no MCP-compatible layer for AI agents to query personal financial data.

## Details
Product Hunt 2026 award winner. Uses Brazil's Open Finance framework. MCP-compatible.
