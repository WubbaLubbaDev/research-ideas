# Browser-Use: Make websites accessible for AI agents
**Date:** 2026-08-13
**Keyword:** AI agent
**Source:** GitHub trending
**URL:** https://github.com/browser-use/browser-use

## Summary
Browser-Use is an open-source tool that makes websites accessible for AI agents, enabling automated web task completion through browser control. It bridges the gap between LLM reasoning and web interaction.

## Idea angle
Use Browser-Use to build AI agents that navigate Indonesian government websites (OSS/RBA business registration, BPJS, DJP tax portal) which are notoriously difficult to use manually. An agent that can auto-fill forms, upload documents, and track application status on these portals would save enormous time for Indonesian entrepreneurs.
