# MOPAD: Growing Status Observation for Individual Oil Palm Trees via UAV

**Source:** GitHub trending

## Summary
MOPAD is a dataset and code for observing individual oil palm tree growing status using UAV (drone) imagery. It uses computer vision to assess tree health, growth patterns, and condition at the individual tree level, enabling precision agriculture for palm oil plantations.

## Idea angle
Integrate MOPAD's tree-level monitoring with SawitPRO's existing GPS plot registration data. The gap: current plantation monitoring is plot-level; individual tree monitoring via drones could identify disease outbreaks, nutrient deficiencies, and yield variations at tree-level granularity. This directly serves smallholder productivity in Indonesia.
