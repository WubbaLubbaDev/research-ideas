# WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution
**Date:** 2026-08-29
**Keyword:** AI agent
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.27454v1

## Summary
WikiSkill is a framework for compiling AI agent experience into persistent knowledge that enables skill evolution. Agents automatically discover skills from their own experience and compile them into reusable knowledge resources. Published Aug 27, 2026.

## Idea angle
Self-evolving skill libraries are the path to agents that improve with use. Instead of manually coding skills, the agent discovers what works and codifies it. For trading agents, this means the agent builds its own playbook of market patterns it has successfully traded — a personalized knowledge base that grows with experience.
