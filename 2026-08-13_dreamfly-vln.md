# DreamFly: Causal Memory for Aerial Vision-Language Navigation
**Date:** 2026-08-13
**Keyword:** AI agent
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.12308v1

## Summary
DreamFly combines causal memory and receding-horizon diffusion planning for aerial vision-language navigation, enabling embodied agents to navigate using visual evidence and language instructions under partial observability.

## Idea angle
Apply aerial VLN to agricultural drone navigation — drones that can follow natural language instructions ('inspect the northeast plantation block for signs of disease') while navigating autonomously. For palm oil plantations covering large areas, natural language drone commands would make aerial monitoring accessible to non-technical plantation managers.

Authors: Yan Deng, Fei Xu. arXiv: 2608.12308.
