## Summary
OpenBB is an open-source financial data platform providing access to market data, fundamentals, economics, and alternative data through a unified API. It serves quants, analysts, and AI agents with both CLI and Python SDK interfaces, and supports custom data connectors.

## Idea angle
Build a localized financial data aggregation layer for Indonesian markets using OpenBB's extension architecture. The gap: Indonesian market data (IDX quotes, BI rates, commodity prices) is fragmented across multiple sources. An OpenBB connector for IDX data would give local quants and AI tools a single API to query Jakarta Composite Index data, CPO prices, and rupiah FX rates.
