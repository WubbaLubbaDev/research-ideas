# Generating Alpha: Hybrid AI-Driven Trading System with Technical Analysis, ML, and Sentiment
**Date:** 2026-08-15
**Keyword:** stock trading
**Source:** arXiv
**URL:** https://arxiv.org/html/2601.19504v1

## Summary
A hybrid AI trading strategy combining EMA/MACD trend-following, RSI/Bollinger mean-reversion, FinBERT sentiment analysis, XGBoost signal generation, and market regime filtering — achieving 135.49% return over 24 months.

## Idea angle
The multi-modal fusion of technical indicators + sentiment + ML is a proven recipe. The regime filter is the differentiator — could build a real-time regime detection module using volatility and return signatures that dynamically switches between trend-following and mean-reversion strategies.
