## Summary
A 63K-star GitHub repo that simulates a hedge fund using multiple AI agents — each agent is a famous investor (Buffett, Burry, Ackman) with their own analysis style, producing collective buy/sell recommendations. Built with Python, LangGraph, and LLM APIs.

## Idea angle
The multi-agent investor-persona pattern is extensible to any domain where different analytical perspectives should be aggregated — credit risk, real estate, or supply chain decisions. You could build a similar system for palm oil price forecasting where each agent represents a different analytical lens (technical, weather, policy, ESG).
