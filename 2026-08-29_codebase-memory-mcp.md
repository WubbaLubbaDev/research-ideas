## Summary
A ~32K-star MCP server that gives AI coding agents persistent memory of codebases — reducing the token burn that happens when agents re-explore large codebases every session. Standardizes on MCP for integration with Claude Code, Cursor, and similar tools.

## Idea angle
Memory is the #1 cost driver for coding agents. By caching codebase understanding across sessions, this MCP server slashes token usage and improves response quality. The pattern applies beyond code — any agent that repeatedly interacts with the same large dataset benefits from a memory layer.
