## Idea angle
Compliance linting for AI agents is a practical tool whose time has come. As regulators worldwide (EU AI Act, NIST AI RMF) set requirements, agent builders need automated checks. A 'compliance CI' pipeline that runs these checks on every agent deployment would be as standard as security scanning is today.
