## Summary
PySawit is a Python library for modeling oil palm growth and yield. It provides simulation tools for predicting palm oil production based on environmental factors, tree age, and management practices — enabling data-driven plantation management decisions.

## Idea angle
Integrate PySawit's growth/yield models with weather data APIs and IoT sensor networks to build a yield prediction dashboard for Indonesian smallholders. The gap: smallholders lack access to scientific yield models; a simplified app that takes plot location, tree age, and basic weather data could help them plan harvesting and fertilizer schedules.
