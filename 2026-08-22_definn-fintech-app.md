## Summary
DEFINN is a React Native + Expo fintech app that unifies stocks, crypto, and UPI payments into one platform. Features real-time crypto market data, wallet connectivity, simulated stock trading, and secure QR payments.

## Idea angle
The unified finance app pattern is perfect for Indonesia — combine IDX stocks, crypto (via local exchanges), and QRIS payments. No Indonesian app currently unifies all three. Build with React Native + local API integrations.
