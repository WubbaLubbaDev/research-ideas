# Inducing Task Models from Computer-Use Traces
**Date:** 2026-08-22
**Keyword:** AI agent
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.20319v1

## Summary
Proposes deriving symbolic, auditable task models from passively recorded computer-use traces (screenshots, mouse/keyboard actions). These models let agents learn how tasks are actually performed and let organizations audit and reuse that knowledge.

## Idea angle
Build a task model induction system for financial workflows — record traders performing analysis and automatically generate reproducible agent workflows. Could democratize quantitative analysis by turning expert procedures into agent skills.

## Details
Authors: Yucheng Jiang, Zora Zhiruo Wang, Ruishi Chen. Published Aug 20, 2026. Key challenge: converting low-level events to high-level models.
