# Open-Source Scanner Finds 97% of AI Agent Code Non-Compliant with EU AI Act
**Date:** 2026-08-29
**Keyword:** AI agent
**Source:** Hacker News
**URL:** https://news.ycombinator.com/item?id=47247314

## Summary
An open-source scanner that analyzes AI agent code for EU AI Act compliance — found 97% of scanned files non-compliant. The scanner maps the AI Act to 6 technical areas: structured logging, input validation, error handling, access control, documentation, and human oversight. Full 5,754-file report is Apache 2.0.

## Idea angle
97% non-compliance is a wake-up call. The scanner's insight — that good engineering practices (like LiteLLM's auth module) happen to satisfy AI Act requirements — means compliance is largely about doing things you should already be doing. The gap is awareness, not capability. A version of this scanner for financial trading agents (SEC/FINRA compliance) would be equally valuable.
