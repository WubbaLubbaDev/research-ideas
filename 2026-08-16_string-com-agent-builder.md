# String.com: AI Agent for Building AI Agents
**Date:** 2026-08-16
**Keyword:** ai-agent
**Source:** Product Hunt
**URL:** https://www.producthunt.com/products/string-com

## Summary
String.com is an AI agent that builds other AI agents — a meta-agent platform. It allows users to describe desired agent behavior in natural language and generates configured agents with appropriate tools, prompts, and workflows. Founded by Tod Sacerdoti (former Pando CEO).

## Idea angle
Build a similar meta-agent platform tailored for Indonesian business needs — generate agents pre-configured for local tasks (WhatsApp customer service, e-commerce fulfillment, government form filing). The gap: existing agent builders don't account for Indonesian business workflows, language patterns, or local platform integrations.
