## Summary
An ultra-low-level C++ stock trading application that interfaces with NASDAQ APIs, focusing on latency minimization and direct market access. Built for performance-critical trading scenarios.

## Idea angle
Low-latency C++ trading infrastructure is typically closed-source and expensive. An open-source NASDAQ API connector with sub-microsecond execution paths would be a foundation for HFT experimentation. The educational value alone — teaching how order matching and market data feeds work at the socket level — justifies the project.
