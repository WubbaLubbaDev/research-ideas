## Summary
A Show HN open-source tool for testing AI agents without using an LLM — deterministic, reproducible agent testing. Posted Aug 28, 2026. Addresses the fundamental problem that LLM-based testing is non-deterministic and expensive.

## Idea angle
Testing agents without LLMs solves the two biggest problems in agent QA: cost and non-determinism. If you can mock the LLM's tool-calling behavior and test the agent's workflow logic separately, you get reproducible CI pipelines. This is the agent equivalent of unit testing — essential for production agent deployments.
