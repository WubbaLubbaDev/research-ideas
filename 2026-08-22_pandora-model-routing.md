# Pandora's AI Model Routing Box — Efficient Allocation with Costly Value Estimation
**Date:** 2026-08-22
**Keyword:** AI agent
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.20316v1

## Summary
Addresses the problem of routing queries across heterogeneous AI models when value estimation itself is costly. Cheap estimators are noisy; accurate estimators are expensive. Proposes efficient allocation strategies balancing estimation cost with routing quality.

## Idea angle
Apply model routing to financial AI agents — route simple queries (price checks) to cheap models and complex queries (earnings analysis) to expensive ones. The cost-quality tradeoff is critical for running agent fleets economically.

## Details
Authors: Adam Fisch, Shubhendu Trivedi, Fantine Huot. Published Aug 20, 2026. Heterogeneous AI systems, routing with costly estimation.
