# Windows 11 Adds AI Agent That Runs in Background with Access to Personal Folders

**Keyword:** AI agent

## Summary
Windows 11 is adding an AI agent that runs in the background with access to personal folders, raising security concerns about what data the agent can read, process, and potentially leak.

## Idea angle
OS-level background agents with file system access are a massive attack surface. Could build a privacy guard layer that intercepts agent file access requests, classifies sensitive files (financial records, credentials), and requires explicit user consent before the agent can read them.
