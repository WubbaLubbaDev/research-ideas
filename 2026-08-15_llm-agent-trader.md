## Summary
An AI-powered stock trading backtesting system that uses LLM-based decision analysis, with a FastAPI backend and Next.js frontend for visualizing and testing LLM-driven trading strategies.

## Idea angle
Combining LLM decision-making with backtesting is the right approach — but the gap is that most LLM backtests suffer from look-ahead bias. Could build a system that strictly enforces temporal data boundaries and tests LLM decisions on truly out-of-sample data with real-time news feeds.
