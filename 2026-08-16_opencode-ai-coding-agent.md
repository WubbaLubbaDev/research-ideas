# OpenCode: Open Source AI Coding Agent
**Date:** 2026-08-16
**Keyword:** ai-agent
**Source:** Hacker News
**URL:** https://opencode.ai/

## Summary
OpenCode is an open-source AI coding agent that provides autonomous code generation, review, and development capabilities. It competes with commercial coding agents like Cursor and Devin but offers full transparency and self-hosting capabilities.

## Idea angle
Deploy OpenCode for Indonesian software development teams that need code generation with data privacy. The gap: Indonesian fintech and banking companies cannot use cloud-hosted AI coding tools due to data sovereignty. A self-hosted coding agent would enable AI-assisted development for regulated industries.
