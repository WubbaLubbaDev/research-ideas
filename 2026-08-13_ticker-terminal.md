**Date:** 2026-08-13
**Keyword:** stock trading
**Source:** GitHub trending

## Summary
Ticker is a terminal-based real-time stock price tracker that displays live market data in a compact terminal UI, supporting multiple exchanges and customizable watchlists.

## Idea angle
Build a terminal ticker for IDX stocks — Indonesian developers and traders who work in terminals would benefit from a lightweight real-time IDX price tracker. Adding support for Jakarta exchange data via Yahoo Finance (which covers IDX) would be straightforward.
