# Teaching LLM Tutors to Withhold Answers: Socratic Behavior Architecture
**Date:** 2026-08-16
**Keyword:** ai-agent
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.12292v1

## Summary
This paper presents a supervisor architecture and evidence-driven method for tuning LLM tutors to exhibit Socratic behavior — asking guiding questions instead of giving answers. A randomized study showed students using unguarded chatbots scored higher in practice but lower on tests without AI, while Socratic versions improved genuine learning.

## Idea angle
Build a Socratic AI tutor for Indonesian students preparing for university entrance exams (SBMPTN/SNBT). The gap: existing Indonesian ed-tech AI tools just give answers; a Socratic agent that guides students through problem-solving would improve actual learning outcomes. Could be deployed via WhatsApp for accessibility.

## Details
- Author: Yusuf Pisan
- Method: supervisor architecture, evidence-driven tuning
- Finding: Socratic tutoring outperforms direct-answer tutoring on delayed tests
