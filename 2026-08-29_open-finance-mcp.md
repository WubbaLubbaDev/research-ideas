# Open Finance MCP — Connect Bank Data with AI Agents
**Date:** 2026-08-29

**Source:** Product Hunt

## Summary
Open Finance MCP is a Product Hunt product that connects bank data with AI agents in ChatGPT and Claude. Uses the MCP (Model Context Protocol) standard to let agents securely read financial data, enabling natural language queries against your actual bank transactions.

## Idea angle
MCP for bank data is the bridge between conversational AI and real financial data. Instead of exporting CSVs or using bank APIs manually, you ask your agent 'how much did I spend on food last month?' and it queries your actual transactions. This pattern — MCP servers for financial data — will be the standard integration layer for AI finance tools.
