## Summary
A 1.4K-star Python repo (created Feb 2026) that provides a memory protocol for trading agents — persistent state across trading sessions so agents learn from past trades and market conditions. MIT licensed.

## Idea angle
Memory is the missing layer in most trading bot frameworks. If an agent can recall that 'this pattern failed 3 times last week,' it adapts. The protocol approach (vs. baking memory into one framework) means it could work with TradingAgents, OpenAlice, or any other system.
