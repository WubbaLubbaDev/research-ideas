# Aurum — Self-hosted Personal Finance OS
**Date:** 2026-08-22
**Keyword:** finance
**Source:** GitHub trending

## Summary
Aurum is a self-hosted personal finance OS that tracks cash flow, net worth, budgets, and all income streams. Free for personal use, it aims to be a complete replacement for commercial personal finance dashboards.

## Idea angle
Build a self-hosted finance dashboard specifically for Southeast Asian users with multi-currency support (IDR, USD, SGD) and local bank API integrations. The gap: most self-hosted finance tools are US/EU-centric and lack Indonesian banking connectors.
