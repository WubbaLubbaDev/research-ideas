## Summary
Moli is a lightweight, fast, high-compatibility headless browser built in Rust specifically for AI agents. Designed as an alternative to Playwright/Puppeteer with better performance and smaller footprint.

## Idea angle
Use Moli as the browser engine for agents that need to scrape Indonesian financial data — IDX announcements, BI regulations, local news sites. Rust's performance is crucial for real-time data gathering across many sources.
