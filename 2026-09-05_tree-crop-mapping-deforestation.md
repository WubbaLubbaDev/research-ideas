# Tree Crop Mapping — Deforestation Links in South America
**Date:** 2026-09-05
**Keyword:** palm oil
**Source:** arXiv
**URL:** https://arxiv.org/abs/2602.17372

## Summary
The first 10m-resolution tree crop map for South America using multi-modal spatio-temporal deep learning on Sentinel-1 and Sentinel-2 imagery. Identifies 11M hectares of tree crops, 23% linked to 2000-2020 forest loss. Reveals that EUDR regulatory maps misclassify smallholder agroforestry as 'forest', risking false deforestation alerts and unfair penalties.

## Idea angle
The EUDR misclassification finding is policy-critical — smallholder farmers could face unfair penalties because regulatory maps can't distinguish agroforestry from forest. Building a tool that uses this higher-resolution mapping to contest false deforestation alerts would protect smallholder livelihoods while supporting legitimate zero-deforestation goals. Directly applicable to Indonesian palm oil smallholders facing EUDR compliance pressure.
