# Agentic Search — Toward More Realistic Corpora for Agentic Search
**Date:** 2026-08-22
**Keyword:** AI agent
**Source:** arXiv
**URL:** http://arxiv.org/abs/2608.20317v1

## Summary
Improves the BrowseComp-Plus benchmark by replacing its small, query-selected corpus with a larger, more realistic document collection (ClimbMix). Separates agent search ability from retriever quality for fairer evaluation.

## Idea angle
Build a realistic corpus benchmark for financial document search — SEC filings, IDX announcements, and analyst reports. Current financial search benchmarks use small curated sets; a realistic corpus would better test agent research capabilities.

## Details
Authors: Sahel Sharifymoghaddam, Lingwei Gu, Yijun Ge. Published Aug 20, 2026. Introduces BrowseComp-Plus_CM corpus.
