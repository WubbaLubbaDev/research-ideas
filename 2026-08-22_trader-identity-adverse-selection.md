# Public Trader Identity — Adverse Selection and Return Predictability
**Date:** 2026-08-22
**Keyword:** stock trading
**Source:** arXiv
**URL:** https://arxiv.org/abs/2608.04373

## Summary
Studies how public trader identity information affects adverse selection and return predictability in financial markets. When trader identities are visible, it changes market dynamics and creates new predictive signals.

## Idea angle
Build a trader behavior analytics tool for IDX — Indonesian exchange has unique participant ID structures. Could create sentiment/flow signals from identified trader categories (retail vs institutional vs foreign).
